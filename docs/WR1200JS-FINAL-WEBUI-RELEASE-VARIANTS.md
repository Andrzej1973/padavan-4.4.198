# Current WR1200JS release profiles

This page replaces the withdrawn Modern/Classic and four-variant matrices.
Classic remains in both release profiles. Hybrid Modern and Classic-free
images are not in the active firmware scope.

| Profile | Firmware WebUI | CAKE/SQM | IoT |
| --- | --- | --- | --- |
| 1 | Classic | Included, factory OFF | Required |
| 2 | Classic | Omitted | Required |

Verify each profile independently by exact revision, toolchain, configuration,
TRX size and SHA256, ROMFS contents, feature gates and supported Classic
controls. Preserve saved settings. Firmware inclusion is not runtime or
physical acceptance. Device changes require separate owner authorization.

See [project delivery scope](PROJECT-DELIVERY-SCOPE.md) for the governing
requirements and [PROJECT_STATUS.md](../PROJECT_STATUS.md) for current evidence.
