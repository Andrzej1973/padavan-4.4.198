# Reset/close execution exclusion54 — local host checks

Pinned predecessor: `.iot-local-check/peer-close-executor53-20261030`.
Candidate: `.iot-local-check/peer-reset-executor54-20261030`, generated by
`prepare-peer-reset-executor.py`. It extends the same MacTabLock-protected
executor with a reset lane and binds it around the public raw PSE/PDMA reset
wrapper. The RTNL try-lock remains nonblocking. No short spinlock spans raw
reset work or task waits. Raw PSE still calls raw PDMA, not its public wrapper.

If close owns or retains the executor, reset requests remain pending without
calling raw hardware work. While raw reset executes, neither close lane can
enter. If radio admission refuses before work, the new reset claim is released.
After raw work, matching software ticket retirement releases execution; this
does not prove hardware success/readiness. Failed ticket retirement retains
the executor and blocks close instead of allowing resources to be freed.
