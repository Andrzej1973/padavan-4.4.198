## Стиль і навігація

Повноцінна внутрішня сторінка YOUHUA WR1200JS українською у стилі прийнятих
попередніх макетів: темно-синє тло, сині акценти, округлі картки, читабельні
поля. Для 5 ГГц — фіолетова піктограма. Зберегти ліве меню та верхню панель
мови, теми й виходу.

Заголовок «Бездротова мережа». Верхні вкладки «Спільні / Окремі діапазони /
IoT 2,4 ГГц (у розробці)», активні «Окремі діапазони». Вибір 2,4/5 ГГц,
активні 5 ГГц. Нижче «Загальні / Гостьова мережа / Міст / Фільтр MAC /
RADIUS / Професійні», активна «Загальні».

## Картки

1. **Основна мережа 5 ГГц**: перемикач радіомодуля; підпис «Показані збережені
   налаштування. Фактичний стан мережі перевіряється окремо». Без вигаданих
   клієнтів, швидкості й статусу «Працює».
2. **Назва мережі**: SSID, демонстраційний YOUHUA-5G, максимум32 байти,
   перемикач приховування SSID.
3. **Захист**: WPA Personal / WPA2 / AES у прикладі. Вибір «Залишити без змін /
   Встановити новий»; порожнє заблоковане поле при збереженні старого пароля.
   Показувати можна лише введений новий пароль, збережений секрет не показувати.
4. **Радіопараметри**: режим (приклад802.11a/n/ac), ширина (приклад20/40/80МГц),
   канал «Автоматично», країна/регіон із налаштувань. Підказка про залежність
   каналів і ширини від регіону та пристрою. Без довільного списку каналів,
   Wi-Fi6/6E,160МГц або WPA3. Фактичні можливості перевірити до реалізації.
5. **Розклад**: перемикач, дні тижня, окремі інтервали буднів/вихідних;
   підказка «Розклад використовує системний час роутера».

## Панель дій і окремий стан

«Скасувати зміни», «Перевірити й застосувати», тимчасове допоміжне посилання
«Перейти до Classic». Попередження: «Застосування радіопараметрів може тимчасово
перервати з’єднання Wi-Fi 5 ГГц». Візуальний макет не дозволяє активувати Apply
до перевірки backend і release gates.

Окремим фрагментом поза основною сторінкою показати стан спільного SSID:
«Назва та захист спільні для 2,4 і 5 ГГц», «Редагувати у Спільних».
Заблоковані лише назва/захист; радіопараметри, приховування SSID і розклад
доступні. Всі значення демонстраційні, передбачити компонування на телефоні.

Посилання Classic — допоміжне під час розробки; фінальний Modern-only реліз
повинен мати повне покриття без залежності від Classic.
