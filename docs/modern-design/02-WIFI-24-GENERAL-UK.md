## Навігація

Зліва зберегти загальне меню. Основний заголовок **Бездротова мережа**.
Перший ряд вкладок: **Спільні** · **Окремі діапазони** · **IoT 2,4 ГГц (у розробці)**.
Активні «Окремі діапазони». Нижче вибір **2,4 ГГц** / **5 ГГц**, активні 2,4 ГГц.

Третій ряд: **Загальні** · **Гостьова мережа** · **Міст** · **Фільтр MAC** ·
**RADIUS** · **Професійні**. Активна вкладка «Загальні». На телефоні цей ряд
може прокручуватися горизонтально; обрана вкладка повинна залишатися видимою.
Перехід між вкладками не застосовує налаштування.

## Компонування зверху вниз

### 1. Картка «Основна мережа 2,4 ГГц»

Ліворуч піктограма Wi-Fi та підпис **2,4 ГГц**. Праворуч перемикач
**Увімкнути радіомодуль 2,4 ГГц**. Це редагування збереженого параметра:
перемикач не має негайно змінювати роутер.

Під ним короткий нейтральний рядок: «Показані збережені налаштування.
Фактичний стан мережі перевіряється окремо». Для невідомого стану не
малювати зелене «Працює» і не вигадувати кількість клієнтів.

### 2. Картка «Назва мережі»

| Елемент | Вигляд / поведінка |
|---|---|
| Назва мережі (SSID) | Поле на всю доступну ширину; праворуч лічильник байтів, максимум 32 |
| Приховати SSID | Окремий перемикач; не прив’язувати до спільного SSID |

Якщо ввімкнений спільний режим, показати невелику плашку:
**«Назва та захист спільні для 2,4 і 5 ГГц»** і посилання **«Редагувати у Спільних»**.
Заблокувати тільки спільні поля SSID/захисту. Не блокувати радіомодуль,
приховування SSID, канал і ширину. Не копіювати значення другого діапазону
лише через відкриття цієї вкладки.

### 3. Картка «Радіопараметри»

| Поле | Значення / залежність |
|---|---|
| Режим мережі | b/g/n; b/g; g/n; лише n; лише g; лише b |
| Ширина каналу | 20 МГц; 20/40 МГц |
| Канал | Автоматично або канали, дозволені для чинної конфігурації регіону |
| Додатковий канал | Нижче / Вище; показувати лише для відповідного режиму 20/40 МГц, коли він має зміст |

Не малювати 14-й канал, «усі канали», Debug-регіон, Wi-Fi 6/ax, 80 МГц,
Beamforming або будь-які режими, яких немає для цього діапазону WR1200JS.
Не вказувати вигадані фактичні частоти/швидкості. «Автоматично» означає
збережений вибір алгоритму, а не результат уже виконаного сканування.

### 4. Картка «Захист основної мережі»

Для основного макета показати **WPA2 Personal + AES**.

| Елемент | Вигляд / поведінка |
|---|---|
| Метод захисту | Випадний список, основний вигляд — WPA Personal |
| Версія WPA | WPA2 / WPA / WPA + WPA2 відповідно до підтримуваних режимів |
| Шифрування | AES / TKIP + AES; перелік залежить від режиму |
| Пароль | Радіокнопки «Залишити без змін» / «Встановити новий» |
| Новий пароль | Масковане поле та показати/приховати тільки нововведене значення |

У звичайному стані збережений пароль не завантажується й не показується.
Порожнє поле не означає стерти пароль. Для нового PSK: 8–63 байти UTF-8
або рівно 64 шістнадцяткові символи. Ліміт SSID також у байтах UTF-8.

Для відкритої мережі замість полів WPA показати попередження **«Мережа без
пароля: дані не захищені шифруванням Wi-Fi»**. У режимі WPA2 таке попередження
не показувати — на попередньому малюнку воно було одночасно з WPA Personal.

Окремим станом можна показати плашку **«Збережено інший режим захисту»**.
Наявні WEP/Enterprise/RADIUS не перетворювати автоматично на WPA Personal.
Не малювати їх увімкненими як уже підтверджені можливості: повний набір і
залежні поля мають пройти окреме зіставлення з точним backend/можливостями
плати. Вони залишаються в обсязі повного перенесення підтримуваних функцій.
WPA3 тут не додавати.

### 5. Посилання «Професійні налаштування»

Показати коротке пояснення: «Розклад, потужність, пороги сигналу та додаткові
параметри доступні у вкладці Професійні». Вони не вилучаються з Modern,
а належать окремому макету. На цю сторінку не додавати розклад по днях,
потужність TX, пороги RSSI, фіксовані швидкості, інтервал ротації ключів
чи керування регіоном.

### 6. Нижня панель дій

**Скасувати зміни** · **Перейти до Classic** · **Перевірити й застосувати**.
Окремо помітка **«Є незбережені зміни»**, коли чернетка відрізняється від
завантаженого стану. Кнопка застосування неактивна до змін і валідної форми.

У поточній реалізації backend Modern Apply ще не готовий: для цього стану
потрібно передбачити замість активного Apply підпис **«Збереження в Modern
ще розробляється»**. Не малювати одночасно активну й нібито заблоковану
версії однієї дії без пояснення, що це два різні стани.

## Діалог перед застосуванням

Заголовок **«Застосувати зміни мережі 2,4 ГГц?»**.
Показати список змін: радіомодуль, SSID, приховування, режим, канал, ширина,
захист. Пароль позначати лише «без змін» / «буде змінено».

Попередження: «З’єднання Wi-Fi може перерватися. Зміна параметрів радіо може
торкнутися основної, гостьової та IoT мереж цього діапазону. Після зміни назви
або пароля повторно підключіться». Не обіцяти безперервність зв’язку.

Кнопки **«Повернутися»** і **«Застосувати»**. Під час запиту не дозволяти
повторного натискання; не показувати успіх лише за спливом таймера.

## Стани для додаткового малюнка або виносок

- Завантаження: нейтральні заглушки, без вигаданих SSID/пароля.
- Не вдалося прочитати конфігурацію: «Повторити» та Classic, збереження недоступне.
- Радіо вимкнено: збережені поля видимі, стан не видається за поломку.
- Спільний SSID/захист: заблоковані тільки відповідні поля, є перехід «Спільні».
- Відкрита мережа: умовне попередження, поля WPA приховані.
- Помилка поля: текст поруч, фокус на першій помилці, не лише червоний колір.
- Запит/очікування повторного підключення: результат ще не підтверджено.
- Сервер відхилив запит: без повідомлення про успіх і без виведення секретів.

## Адаптація до телефона

Одна колонка; назва над полем; елементи без горизонтального виходу за екран.
Нижня панель переноситься на кілька рядків і не перекриває форму. Усі поля,
вкладки й діалоги доступні клавіатурою; помилки пов’язані з відповідними полями.

## Для подальшої реалізації

Modern-маршрут: `/modern/index.html#wifi/split/24/general`.

інвентар сам по собі не доводить підтримку кожної успадкованої функції.

діапазону й не обходити ACK-захист. Поки не отримано готовий макет цієї
сторінки, її візуальну реалізацію не починати.
