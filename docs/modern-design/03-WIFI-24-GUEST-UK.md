## 1. Картка «Гостьова мережа 2,4 ГГц»

Піктограма Wi-Fi, назва й перемикач «Увімкнути гостьову мережу».
Пояснення: «Окрема назва та пароль для гостей. Основна мережа й IoT мають
власні налаштування». Зміна перемикача лише змінює чернетку до застосування.

Підпис «Показані збережені налаштування; фактичний стан перевіряється окремо».
Якщо основний радіомодуль вимкнений, окрема нейтральна плашка:
«Радіомодуль 2,4 ГГц вимкнено. Гостьова мережа не може працювати без нього».
Не вмикати основне радіо автоматично перемикачем Guest.

## 2. Картка «Назва гостьової мережі»

- «Назва мережі (SSID)»: поле, лічильник 0–32 байти UTF-8.
- «Приховати SSID»: окремий перемикач.

Спільний режим основних мереж 2,4/5 ГГц не блокує і не копіює ці поля.
Приклад для малюнка: `YOUHUA-Guest`. Це демонстраційний текст, не значення
для примусового запису на роутер.

## 3. Картка «Захист»

Основний вигляд — WPA2 Personal + AES.

| Елемент | Зміст |
|---|---|
| Захист | Відкрита мережа / WPA Personal |
| Версія WPA | WPA / WPA2 / WPA + WPA2, залежно від чинного режиму |
| Шифрування | AES / TKIP / TKIP + AES; допустимі поєднання перевіряє backend |
| Пароль | «Залишити без змін» / «Встановити новий» |
| Новий пароль | Масковане поле й показати/приховати лише введений новий пароль |

Пароль із роутера не показувати. Для нового PSK: 8–63 байти UTF-8 або
64 шістнадцяткові символи. Порожній ввід не означає стерти збережений ключ.
При відкритій мережі приховати поля WPA й показати жовте попередження:
«Гостьова мережа без пароля: трафік Wi-Fi не захищений шифруванням».
У стані WPA2 такого попередження немає. WPA3, WEP, Enterprise не додавати
до цього Guest-макета: у перевіреному інвентарі гостьової сторінки їх немає.

## 4. Картка «Ізоляція та доступ»

Два незалежні перемикачі з короткими поясненнями:

- **Ізолювати від локальної мережі (LAN)** — «Обмежує доступ гостей до основної
  локальної мережі. Фактичну ізоляцію необхідно перевірити на пристрої».
- **Ізолювати гостьових клієнтів між собою** — «Обмежує прямий обмін між
  клієнтами цієї точки доступу».

Третій перемикач: **Використовувати фільтр MAC-адрес**. Поруч посилання
«Налаштувати фільтр MAC». Правила редагуються на окремій сторінці.
Не описувати MAC-фільтр як заміну паролю або шифруванню.

Ці перемикачі показують збережений запит, а не зелене підтвердження фактичної
ізоляції. Не обіцяти повну IPv4/IPv6 ізоляцію лише через положення перемикача.

## 5. Картка «Розклад гостьової мережі»

Показати окремі блоки «Будні» та «Вихідні»:

- Будні: Пн, Вт, Ср, Чт, Пт — п’ять незалежних виборів днів.
- Вихідні: Сб, Нд — два незалежні вибори.
- У кожному блоці «Початок» і «Кінець», формат години:хвилини (24 години).

Пояснення: «Час роутера використовується для розкладу». Якщо час не
підтверджений, показати повідомлення та посилання до налаштувань часу.
Не вигадувати нові незалежні добові інтервали, таймер відключення через N
годин або новий перемикач розкладу: вихідний backend має два інтервали
для буднів/вихідних. Межі доби, однакові часи та відсутні дні не трактувати
як довільну домовленість дизайну — значення буде звірено з чинним backend.

## 6. Згортаний блок «Додатково»

«Фіксована швидкість передавання»: за замовчуванням «Без фіксації».
Успадковані варіанти зі сторінки Classic залишаються в обсязі перенесення,
але їхній допустимий набір має перевірятися для плати/режиму.
У макеті можна показати закритий список без розкриття всіх варіантів.
Не додавати канал, ширину чи потужність: Guest використовує радіо 2,4 ГГц,
а його радіопараметри налаштовуються на відповідних інших вкладках.

## Діалог підтвердження

«Застосувати зміни гостьової мережі 2,4 ГГц?».
Список змін: увімкнення, SSID, приховування, захист, пароль (лише «змінено» /
«без змін»), ізоляція, MAC-фільтр, розклад, додаткові параметри.

Попередження: «Гостьові клієнти можуть втратити з’єднання. Залежно від
зміни може застосовуватися конфігурація всього діапазону 2,4 ГГц».
Не обіцяти незмінність основних/IoT асоціацій без доказів конкретного apply.
Кнопки «Повернутися» / «Застосувати»; повторне надсилання блокується.

## Альтернативні стани — окремі виноски або додаткові кадри

1. Завантаження: заглушки, без вигаданих налаштувань.
2. Не вдалося завантажити: «Повторити», Classic; Apply недоступний.
3. Guest вимкнено: збережені значення видно, вони не стираються.
4. Основне радіо вимкнено: окреме пояснення, без автоматичного ввімкнення.
5. Відкрита мережа: лише умовне жовте попередження.
6. Помилка SSID/PSK/часу: текст поруч і фокус на першій помилці.
7. Запит триває / зв’язок втрачено: «Результат ще не підтверджено».
8. Сервер відхилив запит: без помилкового успіху й без секретів у повідомленні.

Галерею всіх станів не переносити в постійний інтерфейс. Діалог показується
за відповідною дією. На телефоні одна колонка, навігаційні вкладки можуть
прокручуватися; підписи, фокус, клавіатура й повідомлення доступні.
