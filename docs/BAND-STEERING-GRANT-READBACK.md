# Steering-record readback candidate

The original ioctl dispatchers do not establish that CLI_ADD inserted a record. This extension adds query 0x72 and response 0x73 to both pinned driver variants. Queries only inspect steering table membership; they never insert/delete a record or deauthenticate a station. Replies echo MAC, requested userspace slot and nonzero cookie. State 0 means absent, 1 means present, 2 means error/index mismatch. Presence is not association proof or a promise that the record remains present after the reply.

The modern query reuses the prepared idle structure and requires the full 80-byte message, successful userspace copy, slot below 64 and a nonzero cookie. A present record must have the requested external TableIndex. The legacy query uses its existing 32-byte fields, Time for the cookie and TalbeIndex for the echoed userspace slot; legacy insertion does not store that external slot, so presence is checked by MAC. The legacy dispatcher now rejects copy_from_user failures before dispatching any command. The modern driver retains its existing PID ownership check before the switch.

Preparation validates exact original legacy source and the already prepared modern idle source before writing either file. The driver header layout is unchanged. The isolated workflow extracts the actual query cases into host fixtures with mocked table/send functions, checks absence/presence/index mismatch and malformed requests, exercises the actual legacy dispatcher copy guard, and cross-compiles these fixtures for MIPS. Full vendor driver compilation and actual router behavior remain unverified.

The encoder and decoder support this extension. Still required: a persistent grant controller correlating replies by radio, MAC, slot, cookie, activity generation and deadline; operation deduplication; ordered add/readback and modern reauthentication repair; propagation of protocol failures to the session; production service/UI integration. An arbitrary decoded readback reply is not sufficient to set the policy confirmed_mask.
