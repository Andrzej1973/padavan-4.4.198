# Normalized-event steering coordinator candidate

The coordinator joins session readiness/enable/heartbeat/stop, client observations, policy decisions, verified grant synchronization and non-deauth idle aging. It is a single-owner normalized-event engine; sockets, process ownership, runtime profiles, service hooks and WebUI are not installed by this module.

Only ACTIVE sessions process client/grant/aging events. The coordinator routes modern authentication after client observation to the grant repair path. Legacy 5 GHz deletion invalidates the grant and applies policy cooldown. Capacity exhaustion, invalid time/data, a failed grant proof or send error faults the session and requests best-effort radio disable. Listener ENOBUFS/truncation/loss must invoke fault through the future process owner. A failed session does not prove that both radios are physically disabled.

For each client, idle aging starts only when no grant operation is pending. While an idle proof is active, grant synchronization for that slot pauses. Every absence reply, even stale, invalidates a matching MAC's grant before the aging handler can free the slot. Only a complete dual-radio absence proof frees clients, grant state and policy state together. New activity prevents that deletion. Present/error or timeout retains the record and dirty grants are reconciled after the proof ends. Aging attempts are spaced at least 60 seconds; a proof can pause grant synchronization up to its 3-second deadline. Device reconnect latency under those conditions has not been measured.

Normal shutdown waits for both disabled acknowledgements through the session core. Preconditions remain: fresh/drained event listener, verified driver/profile exclusivity, prepared query/idle handlers and a valid dual-band configuration before init. The future event-loop process must drain events without starving heartbeat/ticks, propagate socket errors and expose honest status.

The integrated host fixture uses the real component modules and mocked non-reentrant driver transport. It covers handshake, bounded 2G grant, periodic presence refresh, idle free/recycle, activity during aging, modern ASSOC/auth repair, legacy kick cooldown, acknowledged stop, capacity exhaustion and transport/clock faults. ASan/UBSan and MIPS compilation are enabled in the isolated workflow. Full vendor-driver compilation, executable service integration and router runtime acceptance remain pending.
