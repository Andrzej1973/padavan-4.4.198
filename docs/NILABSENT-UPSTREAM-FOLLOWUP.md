# Перевірка оновлень nilabsent/padavan-ng

Власник додав цей пункт до роботи 2026-11-05. Виконувати після обов'язкового
IoT у межах аудиту Modern WebUI/Zapret2 та пов'язаних сервісів, до фінальних
release gates. Поточний порядок основної мети зберігається.

## Обов'язкове оновлення даних на момент виконання

Перед початком кожного відповідного пункту повторно перевірити свіжу версію
саме https://github.com/nilabsent/padavan-ng та його актуальну основну гілку.
Зафіксувати дату, точний upstream HEAD, нашу ревізію та донорську ревізію.
Наведений нижче зріз є історичною відправною точкою, а не дозволом переносити
застарілі версії. Перевірити нові коміти, виправлення й залежності, що з'явилися
після нього. Не оновлювати донорський pin і не копіювати дерево цілком без
аналізу сумісності Linux 4.4.198 та наших власних інтеграцій.
