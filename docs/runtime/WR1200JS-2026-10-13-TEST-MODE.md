# WR1200JS — installed firmware operating in test mode

Status recorded 2026-10-13 at the owner's request: the Linux 4.4 firmware is installed and operating on the physical WR1200JS router in **test mode**. This is an observed device baseline, not final acceptance of the complete port.

## Read-only evidence

- SSH to the router succeeded through the restored tunnel.
- `uname -r`: `4.4.198`.
- `nvram get firmver`: `4.4.198.9`. Queried build/extension fields were empty; these fields do not identify an exact current CI artifact. Do not attribute this installation to builds 239–243.
- `/proc/uptime`: `181109.32` seconds on the identity follow-up, approximately 2 days and 2 hours.
- `nslookup example.com 127.0.0.1` returned IPv4 and IPv6 addresses. This confirms the local ordinary resolver answered that query, not every client's Internet access.
- `stubby_enable=0`, `doh_enable=0`: these services remain intentionally disabled after prior DNS troubleshooting.
- `zram_enable=1`, but `/proc/swaps` contained only its header and memory statistics reported zero swap. ZRAM activation remains a confirmed issue on this installed image.
