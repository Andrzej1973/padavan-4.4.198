# Padavan 4.4.198

Firmware project for YOUHUA WR1200JS and additional individually verified router profiles.

## Migration in progress

The existing project history and implementation are being preserved from [youhua-wr1200js-nilab](https://github.com/Andrzej1973/youhua-wr1200js-nilab/tree/experimental/Padavan-4.4.198). This initial repository does not yet contain a complete firmware source tree or verified standalone build.

## Delivery goals

- Preserve the complete WR1200JS configuration on Linux 4.4.198.
- Port Xiaomi Mi Mini with its documented reduced configuration.
- Maintain multiple board profiles and build selected supported boards in one workflow run.
- Publish separate board images and a combined download index with checksums and build status.
- Record exact source origins, revisions, hashes and component licenses in sources.lock.json.
- Preserve source archives and toolchain under this account and create a complete local backup.

Mi Mini radio object compilation is preliminary evidence; full board images and device runtime remain unverified. No remote flashing or reboot is part of repository migration.

Third-party licenses and notices will be preserved individually.
